This site collects write-ups from a private lab: one person, a rack of Dell servers with
BlueField DPUs, an HGX B300 box, a few consumer GPUs, and a NixOS fleet that nets them
together. The work is whatever is interesting and measurable at the time: getting a model
to run on silicon it was not built for, taking a model apart to see where its capacity
goes, building a measurement that answers a question the usual metrics cannot.

Each note is a finished piece of work with a date. The numbers come from runs that are
named in the note, the scripts that produced them are in the repository, and the code
changes go upstream as pull requests that the note links. When a result changes, the note
gets a changelog entry rather than a rewrite, so a citation to a note stays true to what
it said on the day.

The author is whiskey ([github.com/3whiskeywhiskey](https://github.com/3whiskeywhiskey)).
Questions and corrections are welcome as issues on
[github.com/3whiskeywhiskey/research](https://github.com/3whiskeywhiskey/research).
